# Catela Photo Upload Folder

Put your website images in this folder using these exact filenames so `index.html` loads them automatically:

- `logo.png` → Header logo
- `product-small-nut-powdered-cookies.jpg` → Small Nut Powdered Cookies card
- `product-snickerdoodles.jpg` → Snickerdoodles card
- `product-chocolate-chip.jpg` → Chocolate Chip Cookies card

Optional: you can add more images here and reference them in the `Photo Section` inside `index.html`.
